# DSA with Java - LeetCode Practice

## 🌟 Welcome
This repository is a fun, focused Java playground for practicing classic array and string problems from LeetCode, including anagrams, two-sum, duplicates, and recursion patterns.

## 📚 What’s included
- `Anagrams.java`: checks if two strings are anagrams in O(n) time with an alphabet count.
- `two-sum.java`: likely the classic two-sum solution (hashmap / two-pointer style).
- `containtDuplicate.java`: detects duplicates in a list.
- `twodArray.java`: likely 2D array navigation / search logic.
- `recursion.java`: recursion exercise(s) in Java.
- Compiled `.class` files for convenience to run directly.

## 🚀 Run it
From project folder:

```bash
javac *.java
java Anagrams
java Solution   # if Solution has main
```
